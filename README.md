# 🌾 KrishiMitra - Smart Agriculture SaaS Platform

A modern, responsive **Smart Agriculture Analytics Dashboard** built for farmers, admins, and workers. Transformed from a basic college project into a **premium SaaS-style product** with beautiful UI/UX.

## ✨ Features

### **Farmer Dashboard**
- Farm Management (Add, View Farms)
- Task Assignment to Workers
- Inventory Management
- Real-time Analytics & Charts
- Yield Trend Visualization

### **Admin Dashboard**
- User Management
- System Overview & Statistics
- Platform Analytics

### **Worker Dashboard**
- View Assigned Tasks
- Task Completion Tracking
- Performance Insights

### **Modern UI/UX Highlights**
- **Dark & Light Mode** Toggle
- Glassmorphism Design
- Responsive Sidebar Navigation
- Interactive Charts (Chart.js)
- Smooth Animations & Hover Effects
- Professional Typography & Spacing

---

## 🛠 Tech Stack

**Frontend:**
- HTML5, CSS3, JavaScript
- Tailwind CSS
- Chart.js
- Font Awesome Icons

**Backend:**
- Node.js + Express
- JWT Authentication
- PostgreSQL / MySQL

**Other:**
- Responsive Design (Mobile-First)
- Role-based Access (Farmer, Admin, Worker)

## 🎨 Design Highlights

- Complete UI/UX redesign from basic layout to **premium SaaS aesthetic**
- Glassmorphism + modern gradients
- Intuitive information architecture
- Consistent design system across all roles
- Professional dark/light mode support
